# Automatic routing and enrollment checks — 2026-10-09

## Failure observed

An installed router with working hooks accumulated no managed entries during the user's work. Inspection reproduced the gap: an empty store's `UserPromptSubmit` and `PostToolUse` returned `{}`, and using a native skill did not invoke the managed lifecycle. Thus zero managed entries could not establish zero native invocations.

## Deterministic regression checks

The added tests first failed against the previous implementation: no prompt context/check, no enrollment bridge or schedule, and no payload-project state selection. The complete local suite then passed 62 tests. Existing first-load deadlines, active-use guards, source preservation and evidence-bound replacement remain covered.

Independent review found cross-event races. New real-thread regressions reproduced old-task registration overwriting a newer turn and late loading restoring ended-session usage. Check identity binding and atomic session closure fix these cases. Late prompts cannot reopen a closed session; only SessionStart reopens it. Duplicate starts preserve a live check; malformed nested routing state is preserved and hooks report the diagnostic while returning `{}`. Review also exercised 20 concurrent uses from distinct sessions without losing records. The final independent review reported no unresolved findings.

New checks exercise empty-store routing, duplicate turn delivery, once-per-turn pending reminders, independence from review throttling, reviewed enrollment, explicit-only policy, reused identity/deadline, first/last loads, released usage with retained review schedule, old-state compatibility and global-hook project selection. The skill format validator also passed.

## Independent application samples

Five fresh agents applied the previous router to a single installed release-note skill in separate scratch workspaces. All generated the expected artifact, but none registered a managed load. They either read the skill directly or treated the native skill as unmanaged. Final managed entries and usage were empty.

Five fresh agents applied the updated router to equivalent fixtures, with explicit authorization to register the inspected selected copy. All used the enrollment bridge, produced the three-section artifact, released usage, preserved their source file and retained one loaded managed entry with a review time exactly 86400 seconds after first load. The observed load times ranged from 2026-10-09 17:13:42 to 17:15:59 Asia/Shanghai; review times were the corresponding times on October 10.

These application samples did not deliver native prompt hooks; their routing check counts correctly remained zero. They demonstrate instruction-following and lifecycle application, not an end-to-end implicit-activation rate. The explicit registration authorization in the updated samples also prevents treating this as a controlled estimate of the wording's independent effect. The fixture's “43 tests passed” sentence was supplied input, not an additional test execution.

Two further fresh agents received context generated by the actual UserPromptSubmit helper in isolated workspaces. The artifact task registered and loaded its reviewed release-note skill with the supplied check identity, completed its artifact, released usage and retained a 24-hour deadline. Its routing decision was selected with one check and no pending route. The simple arithmetic task recorded none with one check, no pending route and no managed entries. These checks project hook output into agent instructions; they do not establish native host event delivery or implicit-activation reliability.

## Limits

Prompt hooks now emit routing instructions on every request and persist pending/completed decisions. The host model still classifies tasks and runs enrollment; hooks do not forcibly execute semantic decisions. Unsupported/untrusted hooks and instructions-only environments cannot supply the same automatic checks. Native skill use outside this protocol remains untracked. Host-native implicit activation and Windows behavior are not established by these tests.
